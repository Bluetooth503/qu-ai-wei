# 结构反模式与格式类问题

句式壳（二元对比/阶段推进/本质论断等）见 SKILL.md；本文件覆盖段落形状、节奏和格式层面的问题。

## 1. 段落形状：观点 + 解释 + 段尾总结的循环

**反模式：** 每段都是「提出观点 → 解释 → 段尾总结」，且各段长度、功能相似。

**对策：**
- 段落重量错落：短拍 → 中解释 → 厚段落 → 短落点
- 有些段落可以直接以事实开头，不需要观点句引路
- 段尾总结只在真有结论时保留；多数段落以事实、场景、后果或决定收尾

## 2. 平行结构过度整齐

**反模式：** 三个或更多分句共享相同语法和相同情绪坡度（「……，……，……」式排比）；段落分布均匀到「像被排序过」。

**对策：** 打破整齐排比——删一支、扩一支成具体例子、留一支直说。两项优于三项。

## 3. 节奏过匀

**反模式：** 每句都差不多长、差不多抬手、差不多落点；同一种句式骨架反复到能预判下一句形状（尤其二元对比 `不是 X，是 Y`）。

**对策：** 混合长短句。短促有力的句子，然后是需要时间慢慢展开的长句。回读 Pass 2 中若同型句式骨架超出密度阈值，先剔除豁免项（引用、对话、领域逻辑正当的），再把剩余超标处换成中性连接或直接陈述。

## 4. 冒号滥用（概念：解释）

**反模式：** `概念：解释` / `问题：答案` / `原因：结论` 式模板标点。

**对策：** 冒号只在句子自然需要时用。列清单没问题，但每个条目不能都是「名词：定义」的形状。

## 5. 破折号过度使用

**问题：** LLM 用破折号（—）比人类频繁得多，模仿「有力」的销售文案。中英文都适用。

> 这个术语主要由荷兰机构推广——而不是由人民自己。你不会说「荷兰，欧洲」作为地址——但这种错误标记仍在继续——即使在官方文件中 → 这个术语主要由荷兰机构推广，而不是由人民自己。你不会说「荷兰，欧洲」作为地址，但这种错误标记在官方文件中仍在继续。

## 6. 粗体过度使用

**问题：** 机械地用粗体强调短语。中文尤其常见于「**XX：**」式清单。

> 它融合了 **OKR（目标和关键结果）**、**KPI（关键绩效指标）** 和视觉战略工具 → 它融合了 OKR、KPI 和视觉战略工具。

## 7. 内联标题垂直列表

**反模式：** 列表项以粗体标题开头后跟冒号。

> - **用户体验：** 用户体验通过新界面得到显著改善。
> - **性能：** 性能通过优化算法得到增强。

→ 更新改进了界面，通过优化算法加快了加载时间，并添加了端到端加密。

## 8. 表情符号装饰

**反模式：** 用表情符号装饰标题或项目符号。

> 🚀 **启动阶段：** 产品在第三季度发布 → 产品在第三季度发布。

## 9. 引号样式（中文适配注）

英文 AI 常用弯引号；中文通常用中文引号（「」或「」）。若文本出现英文直引号夹杂，统一为中文引号。**不要**把用户原有的中文引号改成英文引号。

## 快速检查清单（回读时过一遍）

- 连续三个句子长度相同？打断其中一个
- 段落以简洁的单行结尾？变换结尾方式
- 揭示前有破折号？删除它
- 解释隐喻或比喻？相信读者能理解
- 用了「此外」「然而」等连接词？考虑删除
- 三段式列举？改为两项或四项
