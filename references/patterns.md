# 标记目录（完整版）

本文件是 qu-ai-wei 的完整标记清单。**只有在这里能定位到触发标记的地方才改。** 每条按三段写：**触发标记**（能在原句指出的词或结构）、**改法**、**边界**（什么时候不该动）。

标点、段落形状、标题、列表等「形状层」问题在 references/structures.md；SKILL.md「高收益标记」里已列出的条目（翻案腔 / 本质拔高 / 助手路标 / 破折号 / 冒号 / 顿号 / 结尾问句 / 阶段推进 / 收窄易答）在此只补词表或不重复整条规则。

同一个动作换任何字面都算命中；清单是举例，不是词表。找不到触发标记的句子原样保留。

## 一、内容拔高

### 1. 夸大意义、遗产与广泛趋势
**触发标记：** 作为/充当、标志着、见证了、是……的体现/证明/提醒、至关重要的作用/时刻、凸显/彰显了其重要性/意义、反映了更广泛的、象征着其持久的/永恒的、为……奠定基础、关键转折点、不断演变的格局、不可磨灭的印记、深深植根于
**改法：** 删掉「某个方面如何代表或促进更广泛主题」的拔高，留下具体事实。
> 加泰罗尼亚统计局于 1989 年正式成立，标志着西班牙区域统计演变史上的关键时刻 → 加泰罗尼亚统计局成立于 1989 年，负责独立于西班牙国家统计局收集和发布区域统计数据。

### 2. 知名度与媒体堆叠
**触发标记：** 独立报道、地方/区域/国家媒体、由知名专家撰写、活跃的社交媒体账号，并列多个来源却不给上下文
**改法：** 只留有实际信息的引用。
> 她的观点被《纽约时报》、BBC、《金融时报》和《印度教徒报》引用。她在社交媒体上拥有活跃存在，有超过 50 万粉丝 → 在 2024 年《纽约时报》的采访中，她认为 AI 监管应该关注结果而不是方法。

### 3. 句尾肤浅分析（悬垂补充）
**触发标记：** 句末跟「突出/强调/彰显……、确保……、反映/象征……、为……做出贡献、培养/促进……、涵盖……」，与前面的事实靠逗号硬绑
**改法：** 切断附加短语；意义若真有信息，改写成独立的判断句。
> 寺庙使用蓝色、绿色和金色，象征着德州的蓝帽花、墨西哥湾和多样景观，反映了社区与土地的深厚联系 → 寺庙使用蓝色、绿色和金色。建筑师表示这些颜色是为了呼应当地的蓝帽花和墨西哥湾海岸。

### 4. 宣传与商业黑话
**触发标记：** 充满活力的、丰富的（比喻）、令人叹为观止的、必游之地、坐落于、位于……的中心、开创性的（比喻）、赋能、抓手、闭环、收窄、兜住、落盘、leverage
**改法：** 换成平实说法；黑话还原成它包装的那个动作。**边界：** 「闭环」「根因」等在控制系统、故障分析里有确切技术含义，保留。
> 坐落在令人叹为观止的区域内，Alamata Raya Kobo 是一座充满活力的城镇，拥有丰富的文化遗产和迷人的自然美景 → Alamata Raya Kobo 是贡德尔地区的一座城镇，以其每周集市和 18 世纪教堂闻名。

### 5. 意义拔高与句尾赞扬
**触发标记：** 标志着新时代、彰显了……的不懈追求、具有重大意义
**改法：** 删尾巴，保留有实际信息的原因、目的和结果；不添加新信源。
> 团队在周三开放了文件导出，标志着协作新时代的到来 → 团队在周三开放了文件导出。
> **边界（不改）：** 页面提供全文搜索，方便读者查找原文中的术语。（后半句是有用的目的）

### 6. 格言与伪深度
**触发标记：** 把抽象名词当万能主语下金句式断言（「X 是 Y 的语言」）
**改法：** 回到原文已有的具体判断；比喻含义不清时，不替作者猜一种新论点。
> 协作是效率的语言。这里的协作，是指两名编辑共同核对一份清单 → 这里的协作是两名编辑共同核对一份清单。
> **边界（不改）：** 被引用、被分析的格言；作者有意且有助于理解的比喻。

### 7. 通用积极结论
**触发标记：** 未来看起来光明、激动人心的时代即将到来、继续追求卓越的旅程
**改法：** 整句为空时进删除清单（bounded）；有实际计划就留计划。
> 公司的未来看起来光明。激动人心的时代即将到来 → 该公司计划明年再开设两个地点。

### 8. 提纲式「挑战与展望」
**触发标记：** 尽管其……面临若干挑战、尽管存在这些挑战、挑战与遗产、未来展望
**改法：** 换成具体问题与具体行动。
> 尽管工业繁荣，Korattur 面临着城市地区典型的挑战，包括交通拥堵和水资源短缺。尽管存在这些挑战，凭借其战略位置……继续蓬勃发展 → 2015 年三个新 IT 园区开业后交通拥堵加剧。市政公司于 2022 年启动雨水排水项目，以解决反复发生的洪水。

### 9. 拟人化喻体
**触发标记：** 「像／相当于 + 一个／一位 + 职业角色（导师、秘书、助手、顾问、管家、审查员、实习生……）」，且喻体带褒义修饰，或后接「不仅……更……」。（实测 AI 是人类的 7.3 倍）
**改法：** 换成这东西实际做了什么，或改用一个具体的人。
> 它就像一位智慧的导师，不仅传授结论，更传授看待世界的多元视角 → 它不只给结论，也讲看待问题的不同角度。
> **边界（不改）：** 比喻本身不是 AI 痕迹（人类用比喻是 AI 的 2.4 倍，独立成段 8 倍）；「像一个老师傅」这类具体的人当喻体，不改。判断：删掉比喻后读者会漏信息，就留。

## 二、句式与节奏

### 10. 翻案腔（词表补充）
SKILL.md「高收益标记」已列。补充别名：并非……而是、不在于……而在于、不只是……更是、不只是……而已、与其说……不如说、表面……实际、看似……实则、你以为……其实、回头才发现、说到底、答案恰恰相反、A 不重要，重要的是 B。
注意：**同一个动作换任何字面都算命中**，判断依据是「先立误解再推翻」这个动作，不是某个固定词。改完回读时专门找一遍变体。

### 11. 阶段推进与收窄易答（词表补充）
**阶段推进**（SKILL.md「高收益标记」已列）：触发 先 A 再 B / 先是……然后 / 从 A 到 B。**边界（不改）：** 步骤、时间或法规条目里编号承担指代功能（「见第三条」）时保留。
**收窄易答框架**：触发 这次只看… / 今天只看… / 这个问题很简单： / 反复的「X 很 X」判断句。改法：下一句能承载意思就去掉铺垫；「很简单」换成具体条件、证据或判断；同节奏的「主语＋很＋形容词」句，一句合并、一句缩短、一句改成具体细节。
> 这个问题很简单：你的段落太整齐 → 问题出在段落节奏上。每一段都差不多长，读者会先感到顺，再感到假。

### 12. 强凑三段式
**触发标记：** 三项并列，其中至少一项没有独立信息；或同段 2+（短段）/ 3+（长段）出现（密度条件）
**改法：** 逐项查是否提供独立信息，只有重复或空泛才合并，不补造第四项。**两项优于三项。**
> 这次更新带来了创新、突破和全新的可能。它新增导出、搜索和批量重命名 → 这次更新新增导出、搜索和批量重命名。
> **边界（不改）：** 导出、搜索和批量重命名是三个不同的功能。

### 13. 相邻句结构同款
**触发标记：** 相邻两句以上，逗号数量相同、成分顺序相同、长度接近，典型是「主语＋动词＋宾语，＋补充说明」连续复现。（实测 AI 每百段 9.41 处，人类 4.81）
**改法：** 打散其中一句的句法——合并、拆分、换语序或改短句。只改句子内部。
> Cloudflare 发长文提了套凭证隔离框架，叫 Agent Access Model。AWS 把 Kiro Crew 开源了，一个能跑一整晚的多 agent 编排平台，标配签名审计日志 → Cloudflare 发长文提了套凭证隔离框架，叫 Agent Access Model。AWS 开源的 Kiro Crew 则是个能跑一整晚的多 agent 编排平台，签名审计日志是标配。
> **边界（不改）：** 清单式段落（操作步骤、并列条款）、对话和引语、文学体裁的有意排比。

### 14. 句式开头复读
**触发标记：** 连续句子因重复主语而拖沓
**改法：** 合并，保留各项动作和时间关系。
> 她检查了门。她检查了门上的锁。随后，她记下了两处问题 → 她检查了门和门上的锁，随后记下两处问题。
> **边界（不改）：** 我看过记录。我问过当事人。我仍然不能确定。（有意的排比）

### 15. 同义词循环
**触发标记：** 同一对象在一段内出现多个称呼（主人公 / 主要角色 / 中心人物）
**改法：** 统一称呼。代词与重复词能让指代稳定，不需要每句换一个说法。
> 主人公面临许多挑战。主要角色必须克服障碍。中心人物最终获得胜利 → 主人公面临许多挑战，但最终获得胜利并回到家中。

### 16. 虚假范围
**触发标记：** 「从 X 到 Y」，而 X 与 Y 不在有意义的一根轴上
**改法：** 直接罗列实指范围。
> 从大爆炸的奇点带到宏伟的宇宙网，从恒星的诞生和死亡到暗物质的神秘舞蹈 → 涵盖大爆炸、恒星形成和当前关于暗物质的理论。

### 17. 系动词回避
**触发标记：** 作为/代表/标志着/充当 [一个]、拥有/设有/提供 [一个]，替代简单的「是/有」
**改法：** 还原系动词。**边界（不改）：** 数量、比较、范围不丢——「超过」≠「等于」，「可以提供」≠「已提供」。
> Gallery 825 作为 LAAA 的当代艺术展览空间。画廊设有四个独立空间，拥有超过 3000 平方英尺 → Gallery 825 是 LAAA 的当代艺术展览空间。画廊有四个房间，总面积 3000 平方英尺。

### 18. 限定词堆叠
**触发标记：** 同层不确定性的限定词叠加（也许可能会、在一定程度上或许）
**改法：** 压成一层，保留证据强度、适用范围和法律提示。
> 在缓存开启的情况下，这项调整也许可能会减少读取时间，目前尚未验证 → 缓存开启时，这项调整可能减少读取时间，目前尚未验证。

### 19. 被动与缺主语
**触发标记：** 施事者已知，被动结构更绕
**改法：** 缩短为主/谓的复杂结构，保留各项动作。**边界（不改）：** 施事者未知（样本已被污染，原因尚未确认）；不补造「系统」「研究人员」当主语。
> 这份稿件被编辑复核后，编辑将其退回 → 编辑复核这份稿件后将其退回。

### 20. 生造复合词
**触发标记：** 用连接号生造标签（「文稿-校对-发布一体化」）
**改法：** 换成它的已有定义。**边界（不改）：** 端到端加密、数据驱动测试等有确切含义的术语。
> 我们采用「文稿-校对-发布一体化」机制，也就是在同一页面完成写稿、校对和发布 → 我们在同一个页面完成写稿、校对和发布。

### 21. 单句收尾与戏剧碎片
**触发标记：** 同一意思拆成几个短句营造力度（文件没了。消失了。再也找不到了。）
**改法：** 合并。**边界（不改）：** 短句承载新事实或有意强调时（我不同意。现在的数据还不够。）

### 22. 起跑式铺垫
**触发标记：** 让我们深入看看、以下是你需要知道的、下面五点
**改法：** 删掉只预告下文的句子；不拿新知识填补删掉的字数。
> 接下来让我们深入看看缓存的作用。缓存可以复用已经取得的结果 → 缓存可以复用已经取得的结果。

### 23. 与假想敌辩论
**触发标记：** 不要误会，我并不是在……；有人会说……
**改法：** 删没有具体内容的自我辩护。**边界（不改）：** 真实反对意见和限制条件（这项措施不能防止断电，但可以减少断电后的数据损失）。

### 24. 段首零主语评论
**触发标记：** 非首段以「听起来／看起来／说白了／值得注意的是／更重要的是／关键在于／问题在于／意味着／不难看出」开头，且整句没有「这／那／其／此／上面」等回指成分。（实测 AI 占非首段 0.61%，人类 0.14%）
**改法：** 补一个回指词（多数加一个「这」字即可），或点明评论对象。不动段落顺序与段内其他文字。
> 值得注意的是，配置数据本来就按「这是谁的」分层放着 → 这一点值得注意，配置数据本来就按「这是谁的」分层放着。
> **边界（不改）：** 首段；原文已有回指成分；对话和引语内部；独立成段的比喻（补「这」字即可，不要删比喻）。

### 25. 顿号密集罗列
**触发标记：** 一个分句内两个以上顿号，连起三项以上并列成分。（实测 AI 3.21/千字，人类 1.78）
**改法：** 能概括就概括；保留三项以上时改变其中一项句法，不排成同一结构。
> 无论是初创公司、中型企业，还是大型集团，都能从中受益 → 各种规模的公司都能用。
> **边界（不改）：** 法规条目、配置项清单、财务科目；Markdown 列表内部；句内同构排比。

## 三、中文特有

### 26. 层叠的「的」
**触发标记：** 长定语难读（连续多个「的」）
**改法：** 拆成两个分句，保留修饰关系，不按字数机械删。
> 这是一个十亿参数的开源小模型的微调的完整方案 → 这是一套完整的微调方案，适用于一个十亿参数的开源小模型。

### 27. 「进行＋动词」
**触发标记：** 正在对……进行……、进行……的调整
**改法：** 换直接动词。**边界（不改）：** 保留正在、完成、计划、次数、范围、结果（正在测试 ≠ 测试了）。
> 我们正在对系统进行全面测试，并计划在周五进行配置调整 → 我们正在全面测试系统，并计划在周五调整配置。

### 28. 被字句堆叠
**触发标记：** 与模式 19 合看，多个被字句叠加
**改法：** 改主动时保持归因和确定程度——「被认为有关」≠「导致」。
> 该问题被社区多次报告，被认为可能与内存泄漏有关，但原因尚未确认 → 社区多次报告这个问题。它被认为可能与内存泄漏有关，但原因尚未确认。

### 29. 四字词排比
**触发标记：** 四字格同义堆叠（稳定可靠、快速响应、易于维护）
**改法：** 只处理空泛或同义堆叠，不把四字节奏当错误。**边界（不改）：** 数量不变、顺序不变、权限不变，分别是三项约束。
> 该方案稳定可靠、快速响应、易于维护 → 这套方案运行稳定、响应快，也方便维护。

### 30. 「随着……的发展」开头
**触发标记：** 随着 X 的不断发展、在……的大背景下，且背景没有独立信息
**改法：** 压缩掉背景铺垫。**边界（不改）：** 变化趋势、时间背景、真实因果（随着文件数量增加，检索时间也在增长）。
> 在技术不断发展的时代背景下，本文讨论文稿校对 → 本文讨论文稿校对。

### 31. 翻译腔（五种结构）
翻译腔本身不等于 AI 味——被动句、名词化、长句都是正常中文写作，人类同样这么用。**只处理下面五种**，其余即使读起来生硬也原样保留；专业术语、法律文本、公文固定表达和已有固定译法不受影响。

**① 过长前置定语**（0.42/千字）：中心名词前修饰超过十五字，或「的」连续两个以上。
> 这是一个能够让团队在不增加人力的情况下显著提升审核速度的工具 → 这个工具能显著提升审核速度，不需要增加人力。

**② 「当……时」前置时间从句**（0.26/千字）：以「当」开头、以「时，」收尾，中间是完整主谓结构。
> 当所有人都能用 AI 写文章时，内容本身就不再是竞争优势 → 所有人都能用 AI 写文章，内容本身就不再是竞争优势。
> **边界（不改）：** 删掉后时间关系变模糊时；「的时候」这类口语说法不是 AI 特征。

**③ 前置话题壳**（0.22/千字）：句首「对于……来说／对……而言／就……而言／关于……／在……方面」，而当句本就以该对象为主语或宾语。
> 对于早期团队来说，招人是最难的事 → 早期团队最难的事是招人。

**④ 句首连接词当路标**（0.18/千字）：段首或句首「然而／因此／此外／与此同时／换言之／总而言之」，尤其相邻段落连续这样开头。
> 此外，成本也是一个需要考虑的因素 → 成本也得考虑。
> **边界（不改）：** 论证确实需要在段落转折处立显式路标时。

**⑤ 「这意味着」式复述句**（0.15/千字）：以「这意味着／这表明／这说明／换句话说」开头，且后面内容与前一句同义。
> 留存率涨到了 72%。这意味着产品找到了 PMF → 留存率涨到 72%，产品找到了 PMF。
> **边界（不改）：** 后面确实给出前句推不出的新结论时。

同一句命中多条时，先按出现顺序靠前的条目改，改完不再叠加。

### 32. 把已有具体数据写回概括表述
**触发标记：** 句中用「显著提升／大幅增长／明显改善／效率的提升／大量／众多」，而同段或相邻段已写着对应的具体数值、时间或对象。（实测数字密度 AI 6.34/千字，人类 17.92）
**改法：** 把已有的具体值提到概括词的位置。**原文没有具体数据时只恢复动词，不许编数字。**
> 新系统实现了效率的提升。处理时间从两小时缩短到四十分钟 → 新系统把处理时间从两小时缩短到四十分钟。
> 团队完成了对流程的优化 → 团队把流程改顺了。（原文没给数据，只恢复动词）
> **边界（不改）：** 原文确实只有概括、没有材料时；不能补，也不能因「太抽象」就删句，可在输出后提示作者材料稀薄。

### 33. 首句复读标题
**触发标记：** 标题之后紧跟一句与标题同义的复述
**改法：** 删复述句；标题后的条件、定义和数据即使词语重复也保留。
> 本节介绍导出限制。下面说明导出限制。单个文件最大为 10 MB → 本节介绍导出限制。单个文件最大为 10 MB。

### 34. 套话收尾
**触发标记：** 总而言之，让我们拭目以待、期待更多可能
**改法：** 删祝愿与重复赞美，保留有实际内容的总结、情绪和行动计划，不替作者编下一步。
> 总而言之，让我们拭目以待，期待更多可能。团队计划在周五继续测试 → 团队计划在周五继续测试。
> **边界（不改）：** 综上，两种方案都无法满足离线要求，暂不采用。

## 四、用词、填充与权威

### 35. 过度使用的 AI 词汇
**触发标记：** 此外、与……保持一致、至关重要、深入探讨、持久的、增强、培养、相互作用、复杂/复杂性、关键（形容词）、格局（抽象名词）、织锦（抽象名词）、证明、宝贵的、充满活力的
**改法：** 只替换空泛、重复或用词不准的地方。**边界（不改）：** 正式词语和工程术语；`重要/关键/核心/提升` 属密度型，全文明显过高时才处理（见第六节）。
> 此外，索马里菜肴的一个显著特征是加入骆驼肉。意大利殖民影响的持久证明是当地烹饪格局中广泛采用意大利面 → 索马里菜肴还包括骆驼肉，被认为是一种美味。意大利殖民期间引入的意大利面菜肴在南部仍很常见。

### 36. 借权威与模糊归因
**触发标记：** 行业报告显示、观察者指出、专家认为、一些批评者认为、多个来源（实际引用很少）
**改法：** 见 SKILL.md「无源引用怎么处理」。**绝不把「专家认为」替换成编造的机构、报告或日期。**
> 由于其独特的特征，浩来河引起了研究人员和保护主义者的兴趣。专家认为它在区域生态系统中发挥着至关重要的作用 → （确有来源时）根据中国科学院 2019 年的调查，浩来河支持多种特有鱼类；（无来源时）保留归因与不确定性。
> **边界（不改）：** 只有笼统归因时，保留归因，不转成确定事实。

### 37. 填充短语
| 改写前 | 改写后 |
|--------|--------|
| 为了实现这一目标 | 为了实现这一点 |
| 由于下雨的事实 | 因为下雨 |
| 在这个时间点 | 现在 |
| 在您需要帮助的情况下 | 如果您需要帮助 |
| 系统具有处理的能力 | 系统可以处理 |
| 值得注意的是数据显示 | 数据显示 |
| 值得注意的是 / 值得一提的是 | 直接删（后接实质内容时，删引导词留骨架） |

### 38. 过度限定
**触发标记：** 可以潜在地可能被认为该政策可能会……（多层软化）
**改法：** 压成一层。
> 可以潜在地可能被认为该政策可能会对结果产生一些影响 → 该政策可能会影响结果。

### 39. 知识边界免责与猜测填充
**触发标记：** 根据我最后的训练更新、虽然具体细节有限/稀缺、基于可用信息
**改法：** 去掉重复免责，不隐藏资料缺口。**边界（不改）：** 「截至某日」若界定数据时效则保留；作者的猜测仍是猜测，不能改成确定年份。
> 虽然关于公司成立的具体细节在现成资料中没有广泛记录，但它似乎是在 20 世纪 90 年代的某个时候成立的 → （有注册文件时）该公司成立于 1994 年；（无来源时）现有材料没有记载成立日期。

## 五、交流与草稿残留

### 40. 客服腔 / 协作痕迹
**触发标记：** 希望这对您有帮助、当然！、一定！、您说得完全正确！、您想要……、请告诉我、Great question!
**改法：** 独立文章中删无内容的问候、夸奖和提议，保留其中的实际信息。**边界（不改）：** 邮件、书信、客服回复里的礼貌用语有用途。
> 好问题！这是导出功能的说明。它支持 CSV。希望这对您有帮助！ → 导出功能支持 CSV。

### 41. 谄媚语气
**触发标记：** 身份认证式夸奖（你问到了问题的核心）、过度接住式共情（你不是敏感，你只是太久没被稳稳接住了）、郑重预告
**改法：** 删姿态层，改回低承诺回应或具体判断。方向/进度认证（走在正确的路上、完全不用担心）只能删除或标注「现有信息不足以判断」，不要降格成弱安抚继续替对方下结论。
> 好问题！您说得完全正确，这是一个复杂的话题。关于经济因素，这是一个很好的观点 → 您提到的经济因素在这里是相关的。

### 42. 谈论上一稿
**触发标记：** 这一段是刚补充的、前面改成了……
**改法：** 删编辑过程。**边界（不改）：** 变更日志、发布说明、迁移指南里的前后差异要保留。
> 这一段是刚补充的说明，内容是文件最大为 10 MB → 文件最大为 10 MB。

## 六、密度条件汇总

多数标记单独出现是正常中文，**只有扎堆才是问题**。看密度的分两类：**密集即改**（开场套话、总结收尾、谄媚句、商业黑话、助手路标）和**扎堆才算**（下面这张表）。

| 类型 | 密度条件 |
|------|---------|
| 三段式 | 短段 < 100 字同段 2+ 个；长段 ≥ 100 字同段 3+ 个 |
| 高频连接词扎堆（此外/然而/因此） | 相邻段落连续以连接词开头 |
| 渲染性修饰词扎堆 | 短段 2+ / 长段 3+ |
| 破折号 | 段落内反复出现；或与作者习惯不符时 |
| 顿号密集 | 一个分句内 2+ 顿号连起 3+ 项 |
| 重要/关键/核心/提升、significant/innovative/effective | 只替换一部分重复命中，必要时不改 |

密度只说明「命中强度」，不等于「改写力度」；力度由 SKILL.md 的 `minimal / standard / aggressive` 决定。
